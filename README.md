# C Expense Tracker

A console-based expense tracking application developed using C.

## Features
- Add expenses with date, category, and amount
- View all expenses
- Calculate total and category-wise expenses
- Search expenses by category
- Delete expenses
- Generate monthly reports
- Save expenses to a file for future use

## Concepts Used
- Structures
- Dynamic memory allocation
- Functions
- File handling
- Loops and switch statements
- String handling

## How to Run

Compile the program:

```bash
gcc expense_tracker.c -o tracker_test.exe
```

Run in PowerShell:

```powershell
.\tracker_test.exe
```

## Note
The program stores expense records locally. Personal expense data is not included in this repository.
